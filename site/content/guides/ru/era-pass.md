Завет эры боевой пропуск сезона на 50 уровней, последний из которых открывается на 35 000 очках. Очки приносят задания пропуска, их 40, и 7 из них обновляются каждый день. Полный день заданий даёт 1 100 очков, разовые задания в сумме 6 600, так что последний уровень берётся примерно за 26 дней из 56 дней эры. Запас времени получается двукратный, и торопиться с пропуском не нужно.

Выдача идёт по трём дорожкам: бесплатной и двум платным. В таблице собрано, что достаётся на каждой из них.

| Что дают | Бесплатно | Пропуск | Большой пропуск |
|---|---|---|---|
| Опыт специализации лорда | 14 000 | 29 000 | 58 000 |
| Билет призыва | 4 | 45 | 70 |
| 100 Алмазов | - | 5 | 39 |
| Общий фрагмент героя UR | 5 | 17 | 34 |
| Ящик с запасами ресурсов (UR) | - | 9 | 18 |
| Случайный запас камней снаряжения | - | 8 | 16 |
| 50 энергии | 1 | 5 | 10 |
| Случайный сундук снаряжения | - | 4 | 4 |
| Очко навыка специализации | - | 1 | 2 |
| Книга сброса навыков | - | - | 1 |
| Книга сброса специализации | - | - | 1 |
| Символ возрождения (Навсегда) | - | - | 1 |
| 50 Алмазов | - | 39 | - |
| Снабжение снаряжения (SSR) | 4 | - | - |
| Ящик с запасами ресурсов (SSR) | 10 | - | - |

Главная строка здесь билеты призыва: бесплатная дорожка даёт 4, большая дорожка 70. В магазине билет стоит 398 алмазов, поэтому по билетам большой пропуск тянет примерно на 27 860 алмазов.

Среди ежедневных заданий есть «совершить любую покупку». Без него в день набирается 900 очков вместо 1 100, срок растягивается, но в 56 дней эры всё равно укладывается.
