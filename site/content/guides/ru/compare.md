## Марлена vs Зоя — какого UR-кэрри? {#marlena-vs-zoya}

**✓ Сначала Марлена, Зоя позже**

| | | |
|---|---|---|
| **Доступность** | С 1-го дня за $1 топап, на 66-й день — бесплатно в Таверне | Только покупка (10 фрагментов на старт) |
| **Доля урона** | ~85% урона отряда в одиночку | Делит ~50/50 с вкачанной Марлена |
| **Тип урона** | Микс физ/энергия по билду | Энергия — нужны энергетические саппорты |
| **Синергия** | Бафается 4× в стандартной компе (ульта Харпер + Белл + пассивка Клэр) | Не стакуется с физическим Джокер |
| **Вердикт F2P** | Главный кэрри всего F2P-пути | Меняй Клэр только если твоя Зоя в высоких звёздах |
