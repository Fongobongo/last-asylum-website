> Данные сверены с игровым клиентом (v1.0.87, [wiki-last-asylum.com](https://wiki-last-asylum.com/ru/wiki/roulette)).

Рулетки крутятся за монеты: одно вращение стоит 1 монету, десять подряд 10. Одна монета выдаётся бесплатно каждый день, и пропускать бесплатное вращение не стоит, потому что среди позиций есть выдача на сто осколков сразу. Рулеток две, и путать их не надо: первая разыгрывает осколки конкретного героя, вторая ресурсы Ворона.

## Рулетка героя

В первой таблице собраны все позиции рулетки героя вместе с шансами на каждую.

| Шанс | Что выпадает |
|---|---|
| 21.50% | Камень снаряжения x120 |
| 20.80% | Припасы уровня с противоядием (SR) x11 |
| 13.10% | Значок навыка x110 |
| 11.40% | Камень снаряжения x180 |
| 9.97% | Фрагмент Синтии x1 |
| 9.97% | Фрагмент Синтии x1 |
| 9.96% | Фрагмент Синтии x1 |
| 1.00% | Фрагмент Синтии x5 |
| 1.00% | Фрагмент Синтии x2 |
| 1.00% | Фрагмент Синтии x2 |
| 0.20% | Меч (UR) x1 |
| 0.10% | Фрагмент Синтии x100 |

Осколки выпадают примерно в 33% вращений, но почти всегда по одному. Крупные выдачи редки: пять осколков приходят в одном проценте случаев, а сто осколков в одной десятой процента.

## Рулетка Ворона

Вторая таблица устроена так же и показывает позиции рулетки Ворона.

| Шанс | Что выпадает |
|---|---|
| 25.90% | Воронья эссенция x2 |
| 22.00% | 1K Вороньих плодов x6 |
| 20.90% | Сундук снаряжения Ворона Ур. 2 x1 |
| 20.20% | 1K Вороньих плодов x6 |
| 5.90% | 10К Вороньих плодов x2 |
| 2.00% | Воронья эссенция x10 |
| 1.50% | Сундук снаряжения Ворона Ур. 4 x1 |
| 1.00% | Воронья эссенция x4 |
| 0.30% | Воронья эссенция x100 |
| 0.10% | Общий фрагмент героя UR x100 |
| 0.10% | Сундук снаряжения Ворона на выбор Ур. 5 x1 |
| 0.10% | Сундук снаряжения Ворона Ур. 5 x1 |

Осколков героев она почти не даёт, зато сыплет вороньими плодами и эссенцией, то есть закрывает ту статью расходов, которая в Вороне самая тяжёлая.
