## Marlena lwn Zoya — hero bawa (carry) UR yang mana? {#marlena-vs-zoya}

**✓ Marlena dahulu, Zoya kemudian**

| | | |
|---|---|---|
| **Ketersediaan** | Hari 1 melalui tambah nilai $1, Hari 66 percuma di Tavern | Berbayar sahaja (10 serpihan untuk mula) |
| **Bahagian Kerosakan (Damage)** | ~85% kerosakan skuad sendirian | Bahagi ~50/50 dengan Marlena maks |
| **Jenis Kerosakan** | Campuran Fizikal/tenaga mengikut binaan | Pusaran tenaga — memerlukan sokongan tenaga |
| **Sinergi** | Ditingkatkan 4× dalam kompo standard (Ultimate Harper + Bell + Pasif Claire) | Tidak bertindan dengan Joker fizikal |
| **Keputusan F2P** | Hero bawa utama untuk keseluruhan laluan F2P | Hanya tukar Claire jika Zoya anda berbintang tinggi |
