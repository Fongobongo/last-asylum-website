Wishing Wheels berputar menggunakan syiling: satu putaran berharga 1 Wish Coin dan sepuluh putaran berturut-turut berharga 10. Satu syiling diberikan secara percuma setiap hari, jadi putaran percuma sangat berbaloi untuk diambil. Terdapat dua roda, yang pertama untuk serpihan wira tertentu dan yang kedua untuk sumber daya raven.

## Roda Wira

Jadual pertama menyenaraikan setiap entri pada roda wira berserta peluangnya.

| Peluang | Hadiah |
|---|---|
| 21.50% | Gearstone x120 |
| 20.80% | Antitoxin Level Supply (SR) x11 |
| 13.10% | Skill Badge x110 |
| 11.40% | Gearstone x180 |
| 9.97% | Cynthia Shard x1 |
| 9.97% | Cynthia Shard x1 |
| 9.96% | Cynthia Shard x1 |
| 1.00% | Cynthia Shard x5 |
| 1.00% | Cynthia Shard x2 |
| 1.00% | Cynthia Shard x2 |
| 0.20% | UR Sword x1 |
| 0.10% | Cynthia Shard x100 |

Serpihan muncul dalam kira-kira satu pertiga daripada putaran, tetapi hampir selalu satu demi satu, dan pembayaran yang lebih besar kekal jarang berlaku.
