许愿转盘消耗金币进行转动：单抽消耗 1 个许愿币，十连抽消耗 10 个。每天免费赠送一个币，因此免费抽奖不容错过。转盘共有两个，第一个产出特定英雄碎片，第二个产出渡鸦资源。

## 英雄转盘

下表列出了英雄转盘上的所有奖项及其概率。

| 概率 | 奖励 |
|---|---|
| 21.50% | 齿轮石 x120 |
| 20.80% | 解毒剂等级补给 (SR) x11 |
| 13.10% | 技能徽章 x110 |
| 11.40% | 齿轮石 x180 |
| 9.97% | 辛西娅 碎片 x1 |
| 9.97% | 辛西娅 碎片 x1 |
| 9.96% | 辛西娅 碎片 x1 |
| 1.00% | 辛西娅 碎片 x5 |
| 1.00% | 辛西娅 碎片 x2 |
| 1.00% | 辛西娅 碎片 x2 |
| 0.20% | UR 剑 x1 |
| 0.10% | 辛西娅 碎片 x100 |

碎片大约在三分之一的抽奖中出现，但几乎每次都只出一个，而大奖则非常罕见。

## 渡鸦转盘

第二张表结构相同，涵盖了渡鸦转盘的内容。

| 概率 | 奖励 |
|---|---|
| 25.90% | 渡鸦精华 x2 |
| 22.00% | 1K 渡鸦果实 x6 |
| 20.90% | 2级渡鸦装备箱 x1 |
| 20.20% | 1K 渡鸦果实 x6 |
| 5.90% | 10K 渡鸦果实 x2 |
| 2.00% | 渡鸦精华 x10 |
| 1.50% | 4级渡鸦装备箱 x1 |
| 1.00% | 渡鸦精华 x4 |
| 0.30% | 渡鸦精华 x100 |
| 0.10% | UR 英雄万能碎片 x100 |
| 0.10% | 5级渡鸦装备自选箱 x1 |
| 0.10% | 5级渡鸦装备箱 x1 |

该转盘几乎不产出英雄碎片，而是以渡鸦果实和精华的形式发放奖励，这是渡鸦养成中最主要的消耗途径。
