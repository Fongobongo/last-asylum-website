试炼会随着常规进程自动完成：装备进阶、专属武器升星、铭文战力提升。总共有 52 个任务，没有一个需要玩家特地去做什么。

它们值得关注的原因在于其产出的货币——通用 UR 英雄碎片。所有任务加起来总共提供 0 个碎片（注：此处原文如此），而积分宝箱还会额外产出更多。解锁一名英雄需要 10 个碎片，而游戏中极少有其他地方能成打地发放通用碎片。

大多数任务都与专属武器的星级挂钩，下表展示了每种任务的数量。

| 任务 | 数量 |
|---|---|
| 装备进阶 | 9 |
| 专属武器达到 1★ | 3 |
| 专属武器达到 2★ | 3 |
| 专属武器达到 3★ | 3 |
| 专属武器达到 4★ | 3 |
| 专属武器达到 5★ | 3 |
| 专属武器达到 6★ | 3 |
| 专属武器达到 7★ | 3 |

## 积分宝箱

完成这些试炼同时也能获得积分，积分可以开启包含碎片和技能徽章的宝箱。

| 积分 | 宝箱奖励 |
|---|---|
| 100 | UR 英雄万能碎片 2，技能徽章 1,250 |
| 200 | UR 英雄万能碎片 2，技能徽章 1,250 |
| 300 | UR 英雄万能碎片 3，技能徽章 1,500 |
| 400 | UR 英雄万能碎片 3，技能徽章 1,500 |
| 500 | UR 英雄万能碎片 4，技能徽章 2,000 |

所有试炼总计可获得 42,250 个技能徽章，与升满一个技能所需的数量相比虽然不多，但这是在玩家本来就会进行的日常进度之上额外获得的奖励。
