## 玛莲娜 vs 佐伊 —— 选哪个 UR 主 C？ {#marlena-vs-zoya}

**✓ 先选玛莲娜，后选佐伊**

| | | |
|---|---|---|
| **获取方式** | 首日充值 1 美元获取，第 66 天酒馆免费获取 | 仅付费（初始 10 个碎片） |
| **伤害占比** | 独自承担全队约 85% 的伤害 | 与满配玛莲娜平分秋色（各占约 50%） |
| **伤害类型** | 根据流派混合物理/能量伤害 | 能量旋风——需要能量辅助 |
| **阵容搭配** | 标准阵容中获得 4 次增益（哈珀大招 + 贝尔 + 克莱尔被动） | 与物理系的Joker（小丑）不叠加 |
| **平民（F2P）结论** | 整个平民路线的主力主 C | 只有在你的佐伊星级很高时，才可以替换克莱尔 |

## 辛西娅 vs 玛莲娜（平民选择） {#cynthia-vs-marlena-f2p}

**✓ 花 1 美元买玛莲娜——但如果你实在无法充值，辛西娅也可以用**

| | | |
|---|---|---|
| **成本** | 约 1,500 钻石（7 次免费抽奖 + 达成 10 个碎片的里程碑 = 完整本体） | 首日充值 1 美元（或第 66 天酒馆免费） |
| **前期强度** | 强势前期主 C（游侠 UR） | 大后期英雄——高星之前较弱 |
| **后期** | 损失 5% 阵营加成 + 哈珀/铭文联动 | 单一战士（Mono-Warrior）体系的核心 |
| **幸运轮盘时机** | 必须在第 1–8 天存钻石 | 无钻石成本 |
| **结论** | 前期爆发可用，后期乏力 | 普遍建议优先选择玛莲娜，而非辛西娅 |
