探索连击是城市周围按编号依次开启的一系列事件，共计 153 个步骤。每个步骤仅奖励一次且不重复，这使得连击成为了一个所有玩家（无论付费与否）都能领取的单次性奖励。正因如此，每个人都会去通关它，而进度放缓仅仅是因为后续的步骤难度会越来越高。

## 完整连击的奖励总额

连击能够提供大量的资源、英雄经验和道具。下表汇总了其中最主要的奖励。

| 奖励 | 总计 |
|---|---|
| 英雄经验 | 6,907,500 |
| 草药 | 1,331,700 |
| 木材 | 999,200 |
| 粮食 | 978,500 |
| 资源补给箱（通用） | 850 |
| 齿轮石 | 700 |
| 招募券 | 145 |
| 赛莉娅碎片 | 85 |
| 克莱尔碎片 | 70 |
| 淬炼钢 | 70 |

招募券值得一提：共有 29 个步骤会发放招募券，总计 145 张，第一张在第 4 步发放。在商店中，一张招募券价值 398 钻石。只有王国之战赛季奖励和付费礼包发放的数量更多。

## 步骤类型

步骤分为几种类型，下表展示了其中占比较多的种类。

| 事件 | 次数 |
|---|---|
| 驱逐瘟疫 | 95 |
| 英雄邀请？ | 20 |
| 神秘力量 | 14 |
| 灾厄枯萎王 | 5 |
| 巨大足迹 | 4 |
| 严厉审判 | 3 |
| 英雄邀请 | 3 |
| 地狱引路人 | 2 |

近三分之二的步骤是瘟疫战斗，其余则是英雄会面和探索发现。战斗以推荐战力来衡量，因此当队伍实力不足时，连击进度就会卡住，在经过一轮升级后才能继续推进。
