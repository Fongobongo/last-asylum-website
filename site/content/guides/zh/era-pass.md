> 数据已与游戏客户端核对（v1.0.87，来源：[wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/era-pass)）。

纪元通行证是一个拥有50级奖励的赛季战令，最后一级需要35,000点数解锁。点数来源于40个通行证任务，其中7个每日刷新，每天价值1,100点数，另有6,600点来自一次性任务。这意味着在56天的纪元周期中，大约26天就能达到最终等级，因此时间安排非常充裕，约为所需时间的两倍。

奖励分为三条路线：一条免费路线和两条付费路线。下表展示了每条路线的产出。

| 奖励 | 免费 | 通行证 | 大型通行证 |
|---|---|---|---|
| 领主专精经验 | 14,000 | 29,000 | 58,000 |
| 招募券 | 4 | 45 | 70 |
| 100 钻石 | - | 5 | 39 |
| UR英雄万能碎片 | 5 | 17 | 34 |
| 资源补给 (UR) | - | 9 | 18 |
| 随机齿轮石补给 | - | 8 | 16 |
| 50 体力 | 1 | 5 | 10 |
| 随机装备宝箱 | - | 4 | 4 |
| 专精技能点 | - | 1 | 2 |
| 复活证明（永久） | - | - | 1 |
| 技能重置书 | - | - | 1 |
| 专精重置书 | - | - | 1 |
| 50 钻石 | - | 39 | - |
| 装备补给 (SSR) | 4 | - | - |
| 资源补给 (SSR) | 10 | - | - |

招募券是付费路线的核心奖励，也是这个通行证值得购买的根本原因；其余各项大多是也能从其他途径获取的资源和材料。
