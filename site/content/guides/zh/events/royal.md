皇家城堡争夺战是**每周一次的城堡争夺赛**：各联盟在**每周固定的一天和同一时间**争夺皇家城堡的占领权。城堡战本身快而简单——战前的准备（出征、增援、圣所等级）才是决定胜负的关键。

本指南涵盖了争夺规则、增援机制、表彰宝箱，以及获胜王国解锁的完整皇家城市头衔系统。

## 运作方式 {#how-how-it-works}

- **每周进行**，每周的固定日期和固定时间——闹钟定一次，时间永不改变。
- **每位玩家只能出征一次。** 整个活动期间你只有一次出征机会。
- **无法加速。** 没有加速道具，也没有加速效果——你出发时的行军速度就是最终抵达的速度。
- **推荐使用集结。** 每位玩家只有一次出征机会，这让每一次出征都至关重要；集结可以将联盟的兵力汇聚成一次强力的进攻，而不是零散的单人送死。
- **初次出征是一场速度赛。** 谁在围攻谁在混战由第一次出征决定——开场哨响时的行军时机比单纯的战力更重要。

## 炮塔与位置定位 {#turrets-and-positioning}

- **炮塔不会激活**：在城堡争夺战中，炮塔是不起作用的——那是[王国远征 (KvK)](/zh/events/kvk/)的机制。这里没有需要突破的炮塔界面。
- **迁城至泥泞地带**如果你不担心遭到攻击——那里**不需要开启防护罩**。泥泞区域是安全的集结地，善加利用。

## 占领与增援 {#capture-and-reinforcement}

- **4小时攻占城堡。** 占领进度会在该时间窗口内持续累积——**高占领百分比时填充更快**，而当遭到防守方反击**处于交战状态时填充较慢**。
- **增援限制：城堡最多30人**。这是一个硬上限——请在战斗开始前规划好增援名单，而不是在战斗进行时。
- **增援会受到消耗。** 防守方会不断蚕食你的驻军——**撤出并重新增援**以重置损耗。一个生命值剩20%的增援部队，其价值远不如该位置上的一个满状态生力军。

## 谁来攻占，谁来采集 {#who-takes-vs-farms}

> 城堡占领者必须达到圣所6级以上——其他人则采集资源格获取积分。

只有**圣所6级及以上**的玩家才能占领城堡。这种分工决定了你的角色：

- **圣所6级+**：出征攻打城堡、发起集结、增援30个驻守名额。
- **其他人**：在城堡周围采集资源格获取活动积分——你的出征依然有收益，只是不在城墙之上。

请在活动开始**前**检查你的圣所等级；一个圣所5级的玩家出征城堡会浪费掉他们仅有的一次出征机会。

## 皇家表彰宝箱 {#commendation-chests}

- **仅限R5（盟主）**——联盟领袖通过**在战后点击城堡**来领取。
- **领取资格：在王国呆满24小时以上。** 在战斗开始前不到一天才跨区来到王国的玩家无法计入宝箱名额。

## 皇家城市头衔 {#royal-titles}

赢得城堡将解锁王国的头衔系统——由头衔持有者施加的限时百分比buff：

| 头衔 | Buff 类型 |
|---|---|
| 研究速度 | 限时研究 % buff |
| 领地发展 | 限时领地 % buff |
| 训练 | 限时部队训练 % buff |
| 治疗 | 限时治疗 % buff |
| 内阁大臣 | 农田产量 buff |

排队机制：

- **排队系统**——玩家按头衔槽排队，先到先得。
- **每个头衔槽持续5分钟。**
- **邮件会在你的头衔槽开始和结束时到达**，以便你确切知道buff何时开始和结束。
- **在头衔槽结束时立即重新申请**——同一个头衔可以重新排队，**重新申请次数不限**。无缝衔接的头衔槽是预期的操作方式。
- **申请后有20分钟冷却时间**——这是对排队的唯一限制。请围绕这个冷却时间来安排你的重新申请。

头衔buff可以与每周日程中的其他内容叠加——在[联盟对决第3阶段](/zh/events/alliance-duel/)期间获得研究头衔，或在[第5阶段](/zh/events/alliance-duel/)期间获得训练头衔，是整个星期玩法核心的双倍收益技巧。
