## Marlena contre Zoya — quelle carry UR ? {#marlena-vs-zoya}

**✓ Marlena d'abord, Zoya plus tard**

| | | |
|---|---|---|
| **Disponibilité** | Jour 1 via achat à 1 $, Jour 66 gratuite dans la taverne | Payant uniquement (10 fragments pour commencer) |
| **Part de dégâts** | ~85 % des dégâts de l'escouade à elle seule | Partage ~50/50 avec une Marlena maximisée |
| **Type de dégâts** | Mélange physique/énergie par build | Tourbillon d'énergie — nécessite des soutiens d'énergie |
| **Synergie** | Buffée 4× dans la composition standard (ult Harper + Bell + passif Claire) | Ne se cumule pas avec Joker physique |
| **Verdict F2P** | La carry principale de tout le parcours F2P | Échangez Claire uniquement si votre Zoya a beaucoup d'étoiles |

## Cynthia contre Marlena pour F2P {#cynthia-vs-marlena-f2p}

**✓ Payez le 1 $ — mais Cynthia fonctionne si vous ne pouvez vraiment pas**

| | | |
|---|---|---|
| **Coût** | ~1 500 diamants (7 tirages gratuits + objectif de 10 fragments = copie complète) | 1 $ achat le Jour 1 (ou gratuit Jour 66 dans la taverne) |
