Wishing Wheels turn for coins: a single spin costs 1 Wish Coin and ten spins in a row cost 10. One coin arrives free every day, so the free spin is worth taking. There are two wheels, the first for a specific hero's shards and the second for raven resources.

## Hero wheel

The first table lists every entry on the hero wheel together with its chance.

| Chance | Prize |
|---|---|
| 21.50% | Gearstone x120 |
| 20.80% | Antitoxin Level Supply (SR) x11 |
| 13.10% | Skill Badge x110 |
| 11.40% | Gearstone x180 |
| 9.97% | Cynthia Shard x1 |
| 9.97% | Cynthia Shard x1 |
| 9.96% | Cynthia Shard x1 |
| 1.00% | Cynthia Shard x5 |
| 1.00% | Cynthia Shard x2 |
| 1.00% | Cynthia Shard x2 |
| 0.20% | UR Sword x1 |
| 0.10% | Cynthia Shard x100 |

Shards come up in about a third of spins, but almost always one at a time, and the larger payouts stay rare.

## Raven wheel

The second table is built the same way and covers the raven wheel.

| Chance | Prize |
|---|---|
| 25.90% | Raven Essence x2 |
| 22.00% | 1K Raven Fruits x6 |
| 20.90% | Lv.2 Raven Gear Chest x1 |
| 20.20% | 1K Raven Fruits x6 |
| 5.90% | 10K Raven Fruits x2 |
| 2.00% | Raven Essence x10 |
| 1.50% | Lv.4 Raven Gear Chest x1 |
| 1.00% | Raven Essence x4 |
| 0.30% | Raven Essence x100 |
| 0.10% | UR Hero Omni Shard x100 |
| 0.10% | Lv.5 Raven Gear Choice Chest x1 |
| 0.10% | Lv.5 Raven Gear Chest x1 |

That wheel hands out almost no hero shards and pays in raven fruit and essence instead, which is the heaviest line of spending in raven development.
