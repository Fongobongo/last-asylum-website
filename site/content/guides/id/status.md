## Peringatan penipuan (penting) {#scam-alert}

Penipu menyamar sebagai pihak resmi untuk mencuri akun. Staf asli **tidak akan pernah** meminta kata sandi, kode verifikasi, atau pembayaran di luar saluran resmi. Aktifkan penautan akun Facebook/Google di Pengaturan.

## Tidak bisa login? Perbaikan cepat {#login-fixes}

- Mulai ulang game sepenuhnya
- Hapus cache game (mungkin perlu login ulang)
- Nonaktifkan VPN jika Anda menggunakannya
- Gunakan tombol **Perbaikan** (sudut kanan atas pada layar pemuatan)
