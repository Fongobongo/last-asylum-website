## Marlena vs Zoya — qual carry UR? {#marlena-vs-zoya}

**✓ Marlena primeiro, Zoya depois**

| | | |
|---|---|---|
| **Disponibilidade** | Dia 1 via $1 de recarga, Dia 66 grátis na Taverna | Apenas pago (10 fragmentos para começar) |
| **Compartilhamento de dano** | ~85% do dano da esquadra sozinha | Divide ~50/50 com uma Marlena maximizada |

| **Sinergia** | Buffada 4× na composição padrão (ult de Harper + Bell + passiva de Claire) | Não acumula com Joker físico |
