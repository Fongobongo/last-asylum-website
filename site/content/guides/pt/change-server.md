Changing server in Last Asylum: Plague means a new character from scratch: the game has no mechanism for moving a city between servers, and purchased heroes and skins do not follow to a new one. Everything players look up under "change server" comes down to four questions: how to start a character on another server, why some servers refuse newcomers, which clock the server runs on, and whether migration is coming. The facts were checked on 9 September 2026 against the game and player reports.

## A city cannot be moved

The server the game assigned to a character stays with it for good. Progress, resources, heroes and every purchase are tied to that character and cannot be taken elsewhere. The only way onto another server is a new character: the login screen offers a list of servers, and a city there starts at level one. The old character stays where it was, one account can hold several characters on different servers, and switching between them goes through the same server list. How the account and its binding work is described on the Account page.

Purchased heroes are absent on the new server: a hero pass applies only to the character it was bought on. Players who tried moving to friends warn about this separately, because the mistake costs money.

## Servers that refuse newcomers

The server list on the login screen does not show every existing server. Servers that have entered the Era of Revival are closed to new characters, so joining a friend there is no longer possible. Players read this as protection for the newcomer: a fresh character on a server older than a hundred and thirty days would stand no chance. What the Era changes is covered on the Season and Era page.

The server number is shown in the profile: the profile icon in the top left corner, with a number such as #218 next to the name. New servers open several times a week; by the end of August 2026 the numbers had passed three hundred and thirty.

Server age decides which events already run there and how far the Era of Revival is, and server numbers are issued in order of opening. ## Server time

Every event, reset and title queue runs on server time rather than the phone clock. By player observation the server clock sits two hours behind Coordinated Universal Time (UTC-2), and most events carry a toggle that shows the same schedule in local time. The event schedule by server day is collected on the Events page.

## Visiting another server

Another server can be viewed from the caravan screen: instead of attacking a caravan the map is scrolled to inspect foreign territories, and a server is found by its number. The second route runs through the Kingdom War: the match information tab lists the group of servers, and its View button moves the camera into a foreign kingdom. Coordinates of a foreign city are saved with the star on it, marked as friend or enemy.

Teleporting with troops to another server works only against the Alliance Duel opponent on raid day and against the Kingdom War opponents, and such a move lasts a day. Plundering caravans and covert operations is allowed only on servers of the same group, and the "exclude own server" checkbox on the caravan screen removes neighbours from the list, which most servers forbid attacking by their own rules.

## Whether migration is coming

The developers' official answer in the community has been the same since spring 2026: transfers between servers are planned, with no timeline. Rumours of a golden ticket, server merges and a move "with all progress" come from players, not the publisher. Separately, an offer in private messages or Discord to "move to another server because this one is shutting down" is a recruiter's trick for another game, covered on the FAQ page.
