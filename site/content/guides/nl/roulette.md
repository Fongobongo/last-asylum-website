Wenswielen draaien voor munten: een enkele draai kost 1 Wensmunt en tien draaien achter elkaar kosten 10. Elke dag krijg je één munt gratis, dus de gratis draai is de moeite waard. Er zijn twee wielen: het eerste voor scherven van een specifieke held en het tweede voor raaf-bronnen.

| 20,80% | Antitoxin Level Supply (SR) x11 |
| 13,10% | Skill Badge x110 |
| 11,40% | Gearstone x180 |
| 9,97% | Cynthia Shard x1 |
| 9,97% | Cynthia Shard x1 |

| 1,00% | Cynthia Shard x5 |
| 1,00% | Cynthia Shard x2 |
| 1,00% | Cynthia Shard x2 |
| 0,20% | UR Sword x1 |
| 0,10% | Cynthia Shard x100 |

Scherven verschijnen bij ongeveer een derde van de draaien, maar bijna altijd één per keer, en de grotere uitbetalingen blijven zeldzaam.
