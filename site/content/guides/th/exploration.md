สายเควสต์สำรวจคือซีรีส์อีเวนต์รอบเมืองที่มีหมายเลขกำกับและปลดล็อกทีละขั้นตอน รวมทั้งหมด 153 ขั้นตอน แต่ละขั้นตอนจะให้รางวัลเพียงครั้งเดียวและไม่วนซ้ำ ทำให้สายเควสต์นี้เป็นแหล่งรับรางวัลแบบครั้งเดียวจบที่ผู้เล่นทุกคน ไม่ว่าจะสายฟรีหรือสายเติมก็ได้รับเหมือนกัน นั่นคือเหตุผลที่ทุกคนเคลียร์มัน และความคืบหน้าจะช้าลงก็ต่อเมื่อขั้นตอนมีความยากขึ้นเรื่อยๆ เท่านั้น

## รางวัลทั้งหมดจากสายเควสต์

สายเควสต์นี้มอบทรัพยากรจำนวนมาก ค่าประสบการณ์ฮีโร่ และไอเทมต่างๆ ตารางด้านล่างรวบรวมรางวัลที่มีมูลค่าสูงสุด

| รางวัล | ทั้งหมด |
|---|---|
| ค่าประสบการณ์ฮีโร่ | 6,907,500 |
| สมุนไพร (Herbs) | 1,331,700 |
| ไม้ (Timber) | 999,200 |
| ข้าวสาลี (Grain) | 978,500 |
| เสบียงทรัพยากร (ทั่วไป) | 850 |
| หินเกียร์ (Gearstone) | 700 |
| ตั๋วรับสมัคร (Recruit Ticket) | 145 |
| เศษชิ้นส่วน ซีเลีย | 85 |
| เศษชิ้นส่วน แคลร์ | 70 |
| เหล็กกล้าชุบแข็ง (Tempered Steel) | 70 |

ตั๋วรับสมัคร (Recruit Tickets) คุ้มค่าแก่การพูดถึง: มี 29 ขั้นตอนที่มอบรางวัลนี้ รวมเป็น 145 ใบ โดยใบแรกจะได้รับที่ขั้นตอนที่ 4 ปกติแล้วตั๋ว 1 ใบมีราคา 398 ไดมอนด์ในร้านค้า มีเพียงรางวัลจากซีซั่นสงครามอาณาจักรและแพ็กเกจเติมเงินเท่านั้นที่แจกมากกว่านี้

## ประเภทของขั้นตอน

ขั้นตอนต่างๆ แบ่งออกเป็นหลายประเภท ตารางด้านล่างแสดงประเภทที่พบได้บ่อยที่สุด

| อีเวนต์ | จำนวนครั้ง |
|---|---|
| ขับไล่โรคระบาด (Banish the Plague) | 95 |
| คำเชิญจากฮีโร่? (Hero Invitation?) | 20 |
| พลังลึกลับ (Mysterious Power) | 14 |
| ราชาแห่งหายนะ Blight King | 5 |
| รอยเท้าขนาดยักษ์ (Giant Footprints) | 4 |
| การตัดสินอันมืดมน (Grim Judgment) | 3 |
| คำเชิญจากฮีโร่ (Hero Invitation) | 3 |
| คู่มือนรก (Hell's Guide) | 2 |

เกือบสองในสามของขั้นตอนเป็นการต่อสู้กับโรคระบาด ในขณะที่ส่วนที่เหลือเป็นการพบปะฮีโร่และการค้นพบสิ่งต่างๆ การต่อสู้จะอิงตามพลังรบ (Might) ที่แนะนำ ดังนั้นสายเควสต์จะหยุดชะงักเมื่อทีมของคุณแข็งแกร่งไม่พอ และจะดำเนินต่อได้หลังจากผ่านรอบอัปเกรดแล้ว
