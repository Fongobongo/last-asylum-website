## 📚 อ้างอิง: Alliance League: Elite, Epic และ Mythic {#wiki-alliance-league}

ที่มา: [wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/alliance-league), ไคลเอนต์ v1.0.87

Alliance League คือการแข่งขันระหว่างพันธมิตรตามฤดูกาลที่มีการเลื่อนชั้นผ่านดิวิชั่นต่างๆ โดยรางวัลจะขึ้นอยู่กับอันดับสองอย่างพร้อมกัน: อันดับที่พันธมิตรทำได้ และอันดับของผู้เล่นภายในพันธมิตรนั้น การอยู่ในพันธมิตรที่แข็งแกร่งเพียงอย่างเดียวไม่เพียงพอ เพราะอันดับส่วนบุคคลจะเป็นตัวกำหนดแถวของตารางรางวัลที่จะได้รับ โดยรางวัลส่วนใหญ่จะอยู่ในรูปแบบของ Study Scrolls

แต่ละลีกจะมีตารางรางวัลของตัวเอง และแถวของรางวัลจะถูกเลือกโดยใช้อันดับพันธมิตรร่วมกับอันดับของผู้เล่นภายในพันธมิตรนั้น

## Elite League

รางวัลจะขึ้นอยู่กับทั้งอันดับของพันธมิตรและอันดับของผู้เล่นภายในพันธมิตรนั้น

| อันดับพันธมิตร | อันดับภายในพันธมิตร | Study Scrolls |
|---|---|---|
| 1-1 | 1-10 | 1,100 |
| 1-1 | 11-30 | 1,050 |
| 1-1 | 31-100 | 1,000 |
| 2-3 | 1-10 | 1,000 |
| 2-3 | 11-30 | 950 |
| 2-3 | 31-100 | 900 |
| 4-16 | 1-10 | 900 |
| 4-16 | 11-30 | 800 |
| 4-16 | 31-100 | 750 |

## Mythic League

รางวัลจะขึ้นอยู่กับทั้งอันดับของพันธมิตรและอันดับของผู้เล่นภายในพันธมิตรนั้น

| อันดับพันธมิตร | อันดับภายในพันธมิตร | Study Scrolls |
|---|---|---|
| 1-1 | 1-10 | 3,120 |
| 1-1 | 11-30 | 2,980 |
| 1-1 | 31-100 | 2,760 |
| 2-3 | 1-10 | 2,760 |
| 2-3 | 11-30 | 2,550 |
| 2-3 | 31-100 | 2,380 |
| 4-16 | 1-10 | 2,380 |
| 4-16 | 11-30 | 2,250 |
| 4-16 | 31-100 | 2,100 |

ช่วงของรางวัลมีตั้งแต่ 750 scrolls ในอันดับต่ำสุดของลีกระดับล่าง ไปจนถึง 3,120 สำหรับอันดับหนึ่งในลีกสูงสุด เพื่อเป็นการเปรียบเทียบ Alliance Duel ในหนึ่งสัปดาห์จะให้รางวัล 840 scrolls สำหรับผู้ชนะและ 420 สำหรับผู้แพ้ และสายการวิจัย Duel ทั้งหมดใช้ต้นทุน 54,110 scrolls ดังนั้นหนึ่งฤดูกาลของลีกจึงมีค่ามากกว่าการแข่งขัน Duel ในหนึ่งสัปดาห์

การเลื่อนดิวิชั่นขึ้นไปจะทำให้รางวัลเพิ่มขึ้นเกือบสองเท่า ในขณะที่การไต่อันดับจาก 100 ขึ้นมาเป็น 10 ภายในพันธมิตรเดียวกันนั้นให้ผลตอบแทนน้อยกว่ามาก ทำให้การเลื่อนชั้นเป็นเป้าหมายที่คุ้มค่ากว่าในทั้งสองเป้าหมายนี้
