> ข้อมูลได้รับการตรวจสอบกับไคลเอนต์เกมแล้ว (เวอร์ชัน 1.0.87, แหล่งที่มา: [wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/trials))

บททดสอบจะเสร็จสิ้นได้เองตามความคืบหน้าปกติ เช่น การอัปเกรดสวมใส่, การเพิ่มดาวอาวุธเฉพาะตัว, หรือการเพิ่มพลังค่าจารึก มีภารกิจทั้งหมด 52 อย่าง และไม่มีภารกิจไหนที่บังคับให้ผู้เล่นต้องเดินทางไปทำอะไรเป็นพิเศษ

สิ่งที่ทำให้ภารกิจเหล่านี้น่าสนใจคือสกุลเงินรางวัลที่ได้รับ ซึ่งก็คือเศษฮีโร่ระดับ UR อเนกประสงค์ ภารกิจทั้งหมดรวมกันมอบเศษฮีโร่จำนวนหนึ่ง และกล่องคะแนนยังมอบเพิ่มเติมให้อีก การปลดล็อกฮีโร่ใช้เศษชิ้นส่วน 10 ชิ้น และมีไม่กี่ที่ในเกมที่จะแจกเศษฮีโร่อเนกประสงค์ทีละเยอะๆ แบบนี้

ภารกิจส่วนใหญ่จะผูกติดกับดวงดาวของอาวุธเฉพาะตัว และตารางด้านล่างนี้จะแสดงว่าภารกิจแต่ละประเภทมีมูลค่าเท่าไร

| ภารกิจ | จำนวน |
|---|---|
| การอัปเกรดสวมใส่ | 9 |
| อาวุธเฉพาะตัวถึง 1★ | 3 |
| อาวุธเฉพาะตัวถึง 2★ | 3 |
| อาวุธเฉพาะตัวถึง 3★ | 3 |
| อาวุธเฉพาะตัวถึง 4★ | 3 |
| อาวุธเฉพาะตัวถึง 5★ | 3 |
| อาวุธเฉพาะตัวถึง 6★ | 3 |
| อาวุธเฉพาะตัวถึง 7★ | 3 |

## กล่องคะแนน

บททดสอบเดียวกันนี้ยังมอบคะแนนให้ด้วย ซึ่งคะแนนจะใช้เปิดกล่องที่มีเศษฮีโร่และตราสกิลอยู่ภายใน

| คะแนน | รางวัลในกล่อง |
|---|---|
| 100 | เศษอเนกประสงค์ฮีโร่ UR 2, ตราสกิล 1,250 |
| 200 | เศษอเนกประสงค์ฮีโร่ UR 2, ตราสกิล 1,250 |
| 300 | เศษอเนกประสงค์ฮีโร่ UR 3, ตราสกิล 1,500 |
| 400 | เศษอเนกประสงค์ฮีโร่ UR 3, ตราสกิล 1,500 |
| 500 | เศษอเนกประสงค์ฮีโร่ UR 4, ตราสกิล 2,000 |

ตราสกิลจากบททดสอบทั้งหมดรวมกันเป็น 42,250 ซึ่งเป็นตัวเลขที่ไม่สูงมากนักเมื่อเทียบกับการอัปเกรดสกิลจนเต็ม แต่ก็เป็นของแถมที่ได้มาฟรีๆ จากความคืบหน้าปกติที่คุณต้องทำอยู่แล้ว
