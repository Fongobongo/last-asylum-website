แคมเปญทำหน้าที่เป็นแหล่งรายได้แบบไม่ได้ใช้งาน (Passive Income) มากกว่าโหมดเนื้อเรื่อง ทุกเลเวลที่เคลียร์ได้จะเพิ่มผลผลิตแบบไม่ได้ใช้งานอย่างถาวร และมันจะเติบโตแบบทวีคูณไม่ใช่แค่ทีละนิด ค่าประสบการณ์ฮีโร่คือสิ่งที่จะได้รับเป็นหลัก ดังนั้นความคืบหน้าของแคมเปญจึงต้องพึ่งพากลุ่มฮีโร่ (Squad) และช่วยผลักดันความแข็งแกร่งไปพร้อมๆ กัน ตารางด้านล่างแสดงให้เห็นว่าค่าประสบการณ์ต่อชั่วโมงเปลี่ยนแปลงอย่างไรตั้งแต่เลเวลแรกจนถึงเลเวลสูงสุด

| เลเวลแคมเปญ | ค่าประสบการณ์ฮีโร่ต่อชั่วโมง |
|---|---|
| 1 | 2,376 |
| 138 | 107,600 |
| 300 | 594,000 |
| 535 ขึ้นไป | 1,188,000 |

ทรัพยากรอื่นๆ ก็ปรับขนาดในลักษณะเดียวกัน เริ่มตั้งแต่เมล็ดพืช 3,688 ต่อชั่วโมงในเลเวลแรก ไปจนถึง 316,800 ที่เลเวลสูงสุด

## พลังที่ต้องใช้ต่อเลเวลแคมเปญ

แต่ละเลเวลจะมีพลัง (Might) ของกลุ่มที่แนะนำ และมันเติบโตเร็วกว่าที่บทแรกๆ จะสื่อถึง

| เลเวล | พลังที่แนะนำ |
|---|---|
| 1 | 11,455 |
| 35 | 205,000 |
| 77 | 780,000 |
| 109 | 1,550,000 |
| 141 | 2,566,200 |
| 185 | 6,909,000 |
| 229 | 11,251,800 |
| 273 | 15,594,600 |
| 317 | 19,937,400 |

หลังจากเลเวล 100 ข้อกำหนดจะเพิ่มขึ้นประมาณสองล้านพลังทุกๆ ยี่สิบเลเวล ซึ่งเป็นจุดที่แคมเปญส่วนใหญ่จะเริ่มไปต่อได้ยาก การเติบโตจำเป็นต้องมาจากการเพิ่มขึ้นแบบทวีคูณ และสิ่งนั้นขึ้นอยู่กับฮีโร่มากกว่าสิ่งก่อสร้าง

##สกุลเงินหลักที่นี่คือค่าประสบการณ์ฮีโร่

ทรัพยากรแบบไม่ได้ใช้งานเป็นสิ่งที่ดี แต่ค่าประสบการณ์คือตัวกำหนดจังหวะ: มันจะถูกนำไปใช้กับเลเวลฮีโร่โดยตรง ซึ่งให้พลังและปลดล็อกอารีน่า ดังนั้นความคืบหน้าของแคมเปญจึงเป็นเรื่องของการอัปเกรดฮีโร่มากกว่าการก่อสร้าง

## ในทางปฏิบัติ

ก่อนจะออฟไลน์ไปพักผ่อนเป็นเวลานาน คววดันแคมเปญให้ไกลที่สุดเท่าที่จะทำได้ก่อน เนื่องจากความแตกต่างระหว่างการเก็บสะสมที่เลเวลสองร้อยและเลเวลสี่ร้อยนั้นเห็นผลทันที คลังเก็บของยังมีขีดจำกัดสูงสุด และรายละเอียดทั้งหมดอยู่ในหน้ากิจวัตรประจำวัน
