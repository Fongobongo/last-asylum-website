## Marlena กับ Zoya — ตัวแบก UR ตัวไหนดีกว่ากัน? {#marlena-vs-zoya}

**✓ Marlena ก่อน, Zoya ทีหลัง**

| | | |
|---|---|---|
| **การได้รับ** | วันที่ 1 ผ่านการเติมเงิน $1, วันที่ 66 ฟรีในโรงเตี๊ยม | จ่ายเงินเท่านั้น (เริ่มต้น 10 ชิ้นส่วน) |
| **สัดส่วนความเสียหาย** | ~85% ของความเสียหายทีมทั้งหมดคนเดียว | แบ่งประมาณ 50/50 กับ Marlena ที่ปั้นจนสุด |
| **ประเภทความเสียหาย** | ผสมกายภาพ/พลังงานตามการสร้าง (build) | พายุหมุนพลังงาน — ต้องการตัวสนับสนุนพลังงาน |
| **ความเข้ากัน (Synergy)** | บัฟ 4× ในคอมพ์มาตรฐาน (สกิลไม้ตาย Harper + Bell + พาซีฟ Claire) | ไม่ทับซ้อนกับ Joker สายกายภาพ |
| **คำตัดสินสำหรับสาย F2P** | ตัวแบกหลักของเส้นทาง F2P ทั้งหมด | เปลี่ยน Claire ออกก็ต่อเมื่อ Zoya ของคุณดาวสูงเท่านั้น |

## Cynthia กับ Marlena สำหรับสาย F2P {#cynthia-vs-marlena-f2p}

**✓ จ่าย $1 เถอะ — แต่ Cynthia ก็ใช้ได้ถ้าคุณทำไม่ได้จริงๆ**

| | | |
|---|---|---|
| **ต้นทุน** | ~1,500 ไดมอนด์ (สุ่มฟรี 7 ครั้ง + ถึงเป้าหมาย 10 ชิ้นส่วน = รับตัวละครเต็ม) | เติมเงิน $1 ในวันที่ 1 (หรือฟรีวันที่ 66 ในโรงเตี๊ยม) |
| **พลังช่วงต้นเกม** | ตัวแบกช่วงต้นที่แข็งแกร่ง (เรนเจอร์ UR) | โตช้า — อ่อนแอจนกว่าจะดาวสูง |
| **ช่วงท้ายเกม** | เสียโบนัสฝ่าย 5% + ความเข้ากันกับ Harper/epigraph | หัวใจหลักของเมต้ามนุษย์เหล็กเดี่ยว (mono-Warrior) |
| **จังหวะกงล้อ** | ต้องเก็บไดมอนด์วันที่ 1–8 | ไม่มีค่าใช้จ่ายไดมอนด์ |
| **คำตัดสิน** | เก่งช่วงแรกแล้วดรอปลง | แนะนำให้ใช้แทน Cynthia ทุกกรณี |

## Annie กับ Joker — ตัวแบกวอร์ล็อกตัวไหนดีกว่ากัน? {#annie-vs-joker}

**✓ Annie เพื่อความคุ้มค่า, Joker สำหรับปิดฉากใน PvP**

| | | |
|---|---|---|
| **บทบาท** | ตัวแบกที่สร้างดาเมจต่อเนื่อง + คุณค่าให้ทีมที่ 8★ | นักฆ่า (Executioner) — โจมตีศัตรูที่ HP น้อยที่สุด |
| **การเข้าถึงของ F2P** | ฮีโร่พาส (ตัวเลือกของชุมชน) | วงล้อปรารถนาหลังวันที่ 15 |
| **ความเข้ากัน (Synergy)** | จับคู่กับตัวสนับสนุนพลังงาน | สายกายภาพ — ไม่เข้าคู่กับ Zoya |
