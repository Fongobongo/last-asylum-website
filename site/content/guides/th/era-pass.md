> ข้อมูลได้รับการตรวจสอบกับไคลเอนต์เกม (v1.0.87, แหล่งที่มา: [wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/era-pass))

Era Pass คือแบทเทิลพาสตามฤดูกาลที่มี 50 เลเวล โดยเลเวลสุดท้ายจะปลดล็อกที่ 35,000 คะแนน คะแนนมาจากภารกิจพาส 40 ภารกิจ โดย 7 ภารกิจจะรีเฟรชทุกวันและให้ 1,100 คะแนนต่อวัน บวกกับอีก 6,600 คะแนนจากภารกิจครั้งเดียวจบ นั่นทำให้เลเวลสุดท้ายใช้เวลาทำประมาณ 26 วันในอีราที่มีความยาว 56 วัน ดังนั้นกำหนดการจึงเผื่อเวลาไว้มากกว่าที่จำเป็นถึงประมาณสองเท่า

รางวัลจะมีด้วยกัน 3 แทรก ได้แก่ แบบฟรีหนึ่งแทรก และแบบเสียเงินสองแทรก ตารางด้านล่างแสดงสิ่งที่แต่ละแทรกมอบให้

|---|---|---|---|
| ค่าประสบการณ์ความสามารถลอร์ด (Lord's Specialty EXP) | 14,000 | 29,000 | 58,000 |
| ตั๋วรับสมัคร (Recruit Ticket) | 4 | 45 | 70 |
| เพชร 100 ชิ้น | - | 5 | 39 |
| ชิ้นส่วนออนนีฮีโร่ UR (UR Hero Omni Shard) | 5 | 17 | 34 |
| เสบียงทรัพยากร (UR) | - | 9 | 18 |
| เสบียงหินเกียร์สุ่ม | - | 8 | 16 |
| พลังงาน 50 | 1 | 5 | 10 |
| หีบเกียร์สุ่ม | - | 4 | 4 |
| แต้มสกิลความสามารถ | - | 1 | 2 |
| หลักฐานการคืนชีพ (ถาวร) | - | - | 1 |
| หนังสือรีเซ็ตสกิล | - | - | 1 |
| หนังสือรีเซ็ตความสามารถ | - | - | 1 |
| เพชร 50 ชิ้น | - | 39 | - |

ตั๋วรับสมัครคือรางวัลชิ้นสำคัญของแทรกแบบเสียเงิน และเป็นเหตุผลว่าทำไมพาสนี้จึงคุ้มค่าที่จะซื้อ ส่วนแถวที่เหลือนั้นคือทรัพยากรและวัสดุที่สามารถหาได้จากแหล่งอื่นเช่นกัน
