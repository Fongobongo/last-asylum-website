## Marlena vs. Zoya — welcher UR-Carry? {#marlena-vs-zoya}

**✓ Zuerst Marlena, später Zoya**

| | | |
|---|---|---|
| **Verfügbarkeit** | Tag 1 via 1-$-Aufladung, Tag 66 kostenlos in der Taverne | Nur kostenpflichtig (10 Fragmente zum Start) |
| **Schadensanteil** | ~85 % des Truppschadens allein | Teilt sich ~50/50 mit einer maximierten Marlena |
| **Schadenstyp** | Mix aus physisch/Energie je nach Build | Energie-Wirbelwind – benötigt Energie-Supporter |
| **Synergie** | 4× gebufft in der Standard-Aufstellung (Harper Ult + Bell + Claire Passiv) | Stapelt sich nicht mit physischem Joker |
| **F2P-Urteil** | Der Haupt-Carry des gesamten F2P-Pfades | Tausche Claire nur aus, wenn deine Zoya ein hohes Sternen-Level hat |

## Cynthia vs. Marlena für F2P {#cynthia-vs-marlena-f2p}

**✓ Zahle den 1 $ — aber Cynthia funktioniert, wenn es wirklich nicht anders geht**

| | | |
|---|---|---|
| **Kosten** | ~1.500 Diamanten (7 Gratis-Spins + Meilenstein von 10 Fragm. = volle Kopie) | 1-$ Tag 1 Aufladung (oder kostenlos Tag 66 in der Taverne) |
| **Frühe Stärke** | Starker früher Carry (Waldläufer UR) | Spätzünder – schwach bis zu hohen Sternen |
| **Late Game** | Verlust von 5 % Fraktionsbonus + Harper/Epigraph-Synergie | Kern der Mono-Krieger-Meta |

| **Urteil** | Brauchbarer früher Boost, fällt später ab | Wird universell gegenüber Cynthia empfohlen |
