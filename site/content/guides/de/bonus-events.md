Bonus events live in one window that opens from the Value Event button with a gift icon in the top right corner of the city screen. Its tabs sit in a row at the top and scroll sideways. Some tabs sell bundles for real money, others pay for ordinary progress and for logging in, so the window is worth a daily visit and not only for purchases.

This is the button that opens the window.

## What the tabs hold

Version 1.0.87 shows nine tabs, listed below in the order the game shows them.
- Heldenpass: a reward track for blessing points with three inner tabs, basic rewards, target tasks and daily tasks, plus a pass chest that opens at 200 points. The track runs on a timer, and four days were left at the time of the check.
- Artisan's Request: no page yet.
- Aufladungsbelohnung: no page yet.
- Wöchentliches Spezial: no page yet.
- Hero's Trial: fifteen task tracks tied to hero stars that pay skill badges and gear stones. At the time of the check the window held two tabs with this name.
- Helden versammeln sich: no page yet.
- VIP Angebot: bundles with hero shards and VIP points, each limited to a single purchase. The points go into the common VIP scale.
- Anmelde-Belohnungen: no page yet.

The names are written the way the game shows them. Pages for the tabs without a description will appear as they are checked.
