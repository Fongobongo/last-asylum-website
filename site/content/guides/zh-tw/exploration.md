探索連擊是城市周圍按編號依次開啓的一系列事件，共計 153 個步驟。每個步驟僅獎勵一次且不重複，這使得連擊成爲了一個所有玩家（無論付費與否）都能領取的單次性獎勵。正因如此，每個人都會去通關它，而進度放緩僅僅是因爲後續的步驟難度會越來越高。

## 完整連擊的獎勵總額

連擊能夠提供大量的資源、英雄經驗和道具。下表彙總了其中最主要的獎勵。

| 獎勵 | 總計 |
|---|---|
| 英雄經驗 | 6,907,500 |
| 草藥 | 1,331,700 |
| 木材 | 999,200 |
| 糧食 | 978,500 |
| 資源補給箱（通用） | 850 |
| 齒輪石 | 700 |
| 招募券 | 145 |
| 賽莉婭碎片 | 85 |
| 克萊爾碎片 | 70 |
| 淬鍊鋼 | 70 |

招募券值得一提：共有 29 個步驟會發放招募券，總計 145 張，第一張在第 4 步發放。在商店中，一張招募券價值 398 鑽石。只有王國之戰賽季獎勵和付費禮包發放的數量更多。

## 步驟類型

步驟分爲幾種類型，下表展示了其中佔比較多的種類。

| 事件 | 次數 |
|---|---|
| 驅逐瘟疫 | 95 |
| 英雄邀請？ | 20 |
| 神祕力量 | 14 |
| 災厄枯萎王 | 5 |
| 巨大足跡 | 4 |
| 嚴厲審判 | 3 |
| 英雄邀請 | 3 |
| 地獄引路人 | 2 |

近三分之二的步驟是瘟疫戰鬥，其餘則是英雄會面和探索發現。戰鬥以推薦戰力來衡量，因此當隊伍實力不足時，連擊進度就會卡住，在經過一輪升級後才能繼續推進。
