試煉會隨着常規進程自動完成：裝備進階、專屬武器升星、銘文戰力提升。總共有 52 個任務，沒有一個需要玩家特地去做什麼。

它們值得關注的原因在於其產出的貨幣——通用 UR 英雄碎片。所有任務加起來總共提供 0 個碎片（注：此處原文如此），而積分寶箱還會額外產出更多。解鎖一名英雄需要 10 個碎片，而遊戲中極少有其他地方能成打地發放通用碎片。

大多數任務都與專屬武器的星級掛鉤，下表展示了每種任務的數量。

| 任務 | 數量 |
|---|---|
| 裝備進階 | 9 |
| 專屬武器達到 1★ | 3 |
| 專屬武器達到 2★ | 3 |
| 專屬武器達到 3★ | 3 |
| 專屬武器達到 4★ | 3 |
| 專屬武器達到 5★ | 3 |
| 專屬武器達到 6★ | 3 |
| 專屬武器達到 7★ | 3 |

## 積分寶箱

完成這些試煉同時也能獲得積分，積分可以開啓包含碎片和技能徽章的寶箱。

| 積分 | 寶箱獎勵 |
|---|---|
| 100 | UR 英雄萬能碎片 2，技能徽章 1,250 |
| 200 | UR 英雄萬能碎片 2，技能徽章 1,250 |
| 300 | UR 英雄萬能碎片 3，技能徽章 1,500 |
| 400 | UR 英雄萬能碎片 3，技能徽章 1,500 |
| 500 | UR 英雄萬能碎片 4，技能徽章 2,000 |

所有試煉總計可獲得 42,250 個技能徽章，與升滿一個技能所需的數量相比雖然不多，但這是在玩家本來就會進行的日常進度之上額外獲得的獎勵。
