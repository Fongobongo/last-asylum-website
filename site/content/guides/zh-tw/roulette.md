許願轉盤消耗金幣進行轉動：單抽消耗 1 個許願幣，十連抽消耗 10 個。每天免費贈送一個幣，因此免費抽獎不容錯過。轉盤共有兩個，第一個產出特定英雄碎片，第二個產出渡鴉資源。

## 英雄轉盤

下表列出了英雄轉盤上的所有獎項及其概率。

| 概率 | 獎勵 |
|---|---|
| 21.50% | 齒輪石 x120 |
| 20.80% | 解毒劑等級補給 (SR) x11 |
| 13.10% | 技能徽章 x110 |
| 11.40% | 齒輪石 x180 |
| 9.97% | 辛西婭 碎片 x1 |
| 9.97% | 辛西婭 碎片 x1 |
| 9.96% | 辛西婭 碎片 x1 |
| 1.00% | 辛西婭 碎片 x5 |
| 1.00% | 辛西婭 碎片 x2 |
| 1.00% | 辛西婭 碎片 x2 |
| 0.20% | UR 劍 x1 |
| 0.10% | 辛西婭 碎片 x100 |

碎片大約在三分之一的抽獎中出現，但幾乎每次都只出一個，而大獎則非常罕見。

## 渡鴉轉盤

第二張表結構相同，涵蓋了渡鴉轉盤的內容。

| 概率 | 獎勵 |
|---|---|
| 25.90% | 渡鴉精華 x2 |
| 22.00% | 1K 渡鴉果實 x6 |
| 20.90% | 2級渡鴉裝備箱 x1 |
| 20.20% | 1K 渡鴉果實 x6 |
| 5.90% | 10K 渡鴉果實 x2 |
| 2.00% | 渡鴉精華 x10 |
| 1.50% | 4級渡鴉裝備箱 x1 |
| 1.00% | 渡鴉精華 x4 |
| 0.30% | 渡鴉精華 x100 |
| 0.10% | UR 英雄萬能碎片 x100 |
| 0.10% | 5級渡鴉裝備自選箱 x1 |
| 0.10% | 5級渡鴉裝備箱 x1 |

該轉盤幾乎不產出英雄碎片，而是以渡鴉果實和精華的形式發放獎勵，這是渡鴉養成中最主要的消耗途徑。
