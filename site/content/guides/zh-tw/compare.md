## 瑪蓮娜 vs 佐伊 —— 選哪個 UR 主 C？ {#marlena-vs-zoya}

**✓ 先選瑪蓮娜，後選佐伊**

| | | |
|---|---|---|
| **獲取方式** | 首日充值 1 美元獲取，第 66 天酒館免費獲取 | 僅付費（初始 10 個碎片） |
| **傷害佔比** | 獨自承擔全隊約 85% 的傷害 | 與滿配瑪蓮娜平分秋色（各佔約 50%） |
| **傷害類型** | 根據流派混合物理/能量傷害 | 能量旋風——需要能量輔助 |
| **陣容搭配** | 標準陣容中獲得 4 次增益（哈珀大招 + 貝爾 + 克萊爾被動） | 與物理系的Joker（小丑）不疊加 |
| **平民（F2P）結論** | 整個平民路線的主力主 C | 只有在你的佐伊星級很高時，纔可以替換克萊爾 |

## 辛西婭 vs 瑪蓮娜（平民選擇） {#cynthia-vs-marlena-f2p}

**✓ 花 1 美元買瑪蓮娜——但如果你實在無法充值，辛西婭也可以用**

| | | |
|---|---|---|
| **成本** | 約 1,500 鑽石（7 次免費抽獎 + 達成 10 個碎片的里程碑 = 完整本體） | 首日充值 1 美元（或第 66 天酒館免費） |
| **前期強度** | 強勢前期主 C（遊俠 UR） | 大後期英雄——高星之前較弱 |
| **後期** | 損失 5% 陣營加成 + 哈珀/銘文聯動 | 單一戰士（Mono-Warrior）體系的核心 |
| **幸運輪盤時機** | 必須在第 1–8 天存鑽石 | 無鑽石成本 |
| **結論** | 前期爆發可用，後期乏力 | 普遍建議優先選擇瑪蓮娜，而非辛西婭 |
