紀元通行證是一個擁有50級獎勵的賽季戰令，最後一級需要35,000點數解鎖。點數來源於40個通行證任務，其中7個每日刷新，每天價值1,100點數，另有6,600點來自一次性任務。這意味着在56天的紀元週期中，大約26天就能達到最終等級，因此時間安排非常充裕，約爲所需時間的兩倍。

獎勵分爲三條路線：一條免費路線和兩條付費路線。下表展示了每條路線的產出。

| 獎勵 | 免費 | 通行證 | 大型通行證 |
|---|---|---|---|
| 領主專精經驗 | 14,000 | 29,000 | 58,000 |
| 招募券 | 4 | 45 | 70 |
| 100 鑽石 | - | 5 | 39 |
| UR英雄萬能碎片 | 5 | 17 | 34 |
| 資源補給 (UR) | - | 9 | 18 |
| 隨機齒輪石補給 | - | 8 | 16 |
| 50 體力 | 1 | 5 | 10 |
| 隨機裝備寶箱 | - | 4 | 4 |
| 專精技能點 | - | 1 | 2 |
| 復活證明（永久） | - | - | 1 |
| 技能重置書 | - | - | 1 |
| 專精重置書 | - | - | 1 |
| 50 鑽石 | - | 39 | - |
| 裝備補給 (SSR) | 4 | - | - |
| 資源補給 (SSR) | 10 | - | - |

招募券是付費路線的核心獎勵，也是這個通行證值得購買的根本原因；其餘各項大多是也能從其他途徑獲取的資源和材料。
