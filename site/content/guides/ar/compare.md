## مارلينا ضد زويا — أي بطلة هجومية رئيسية (Carry) أفضل؟ {#marlena-vs-zoya}

**✓ مارلينا أولاً، وزويا لاحقاً**

| | | |
|---|---|---|
| **الإتاحة** | اليوم الأول عبر شحن دولار واحد، أو مجاناً في اليوم 66 في الحانة (Tavern) | مدفوعة فقط (10 شظايا للبداية) |
| **حصة الضرر** | ~85% من ضرر الفريق بمفردها | تقسم الضرر بنسبة ~50/50 مع مارلينا بأقصى تطوير |
| **نوع الضرر** | مزيج بين الضرر الجسدي وطاقة حسب البناء | دوامة طاقة — تحتاج إلى داعمين للطاقة |
| **التناغم (Synergy)** | تعزيز 4 أضعاف في التشكيلة الأساسية (مهارة هاربر الخارقة + بيل + مهارة كلير الكامنة) | لا تتوافق مع جوكر (Joker) ذي الضرر الجسدي |
| **رأي اللاعبين المجانيين (F2P)** | البطلة الهجومية الأساسية في مسار اللعب المجاني بالكامل | استبدل كلير فقط إذا كانت زويا لديك ذات نجوم عالية |

## سينثيا ضد مارلينا للاعبين المجانيين (F2P) {#cynthia-vs-marlena-f2p}

**✓ ادفع دولاراً واحداً — لكن سينثيا تعمل بشكل جيد إن لم تستطع حقاً**

| | | |
|---|---|---|
| **التكلفة** | ~1,500 جوهرة (7 لفات مجانية + مرحلة الوصول لـ 10 شظايا = نسخة كاملة) | شحن دولار واحد في اليوم الأول (أو مجاناً في اليوم 66 في الحانة) |
| **القوة المبكرة** | بطلة هجومية قوية في البداية (من فئة الرماة UR) | تنمو ببطء — ضعيفة حتى تصل إلى نجوم عالية |
| **اللعب المتأخر** | تفقد 5% من مكافأة الفصيل + تناغم هاربر/الإبيغراف | أساس تجميعة المحاربين الأحادية (mono-Warrior) |
| **توقيت عجلة الحظ** | يجب توفير الجواهر في الأيام 1-8 | لا توجد تكلفة جواهر |
| **التقييم** | مفيدة كدفعة مبكرة، لكنها تضعف لاحقاً | يُنصح بها عالمياً على حساب سينثيا |

## آني ضد جوكر — أي بطل هجومي من فئة المشعوذين (Warlock) أفضل؟ {#annie-vs-joker}

**✓ آني للقيمة، وجوكر لحسم المعارك في طور اللاعب ضد اللاعب (PvP)**

| | | |
|---|---|---|
| **الدور** | ضرر مستدام + قيمة للفريق عند 8 نجوم★ | جزار/منفذ — يستهدف الأعداء ذوي نقاط الصحة الأقل |
| **الوصول للاعبين المجانيين (F2P)** | تذكرة الأبطال (Hero Pass - خيار المجتمع) | عجلة الحظ (Wishing Wheel) بعد اليوم 15 |
| **التناغم (Synergy)** | تتزاوج مع داعمي الطاقة | جسدية — لا تتزاوج مع زويا |
| **الأفضل في** | المعارك الطويلة، ومحتوى الوحوش | تنظيف الساحة في طور (PvP) بعد أن تقوم مارلينا بإضعاف الأعداء |

## أولفريد (Ulfrid) ضد بيلي (Billy) — الخط الأمامي للمشعوذين (Warlock) {#ulfrid-vs-billy}

**✓ مثالياً يجب جمعهما معاً؛ وإذا وجب اختيار واحد — أولفريد للعب الفردي ضد الزعماء (PvE)، وبيلي لمواجهة التحكم بالحشود (Anti-CC) في (PvP)**

| | | |
|---|---|---|
| **الدور** | دبابة تعكس الضرر (تم تغيير اسمها من براين) | دبابة مضادة للتحكم بالحشود ومضعفة للأعداء |
| **المهارة الأساسية** | عكس الضرر + البقاء على قيد الحياة | مناعة ضد الصعق (تتصدى للسيدة الحمراء Red Lady) + تقليل الضرر المتخذ من الطاقة بنسبة -8% |
| **إضعاف الأعداء (Debuff)** | تقليل الضرر ضد الوحوش | تطبيق تأثير إضعاف بزيادة الضرر المتخذ على 3 أعداء عشوائيين (الحقيقة والأكاذيب) |
| **المصدر** | استدعاء UR / لافتة اليوم 43 | تذكرة الأبطال (Hero Pass) / عرض اليوم 85 اليومي |
| **التقييم** | العمود الفقري للخط الأمامي لمشعوذين التشكيلة الأحادية | إلزامي في طور (PvP) ضد تحكم الرماة بالحشود |
