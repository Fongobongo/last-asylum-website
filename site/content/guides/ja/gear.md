## 基本ルール {#cardinal-rules}

- **UR（オレンジ）のみを製作する。** 緑や青の装備は無料でドロップするため、アップグレードに素材を無駄遣いしてはいけません。不要な低ティア装備は分解しましょう。
- **一度に1部隊ずつ強化する。** 効率よく進めるには、第1部隊のみを装備で固めます。アタッカーには剣とグローブ、タンクにはチェストプレートとブーツを優先します。
- 装備を配分する際は、**SSRヒーローよりもURヒーローを優先**します。
- 品質ランク：**ゴールド（UR） > パープル（SSR） > ブルー（SR） > グリーン（R） > グレー**。

## スロットの優先順位 {#slot-priorities}

| ヒーローの役割 | 優先度1 | 優先度2 | 備考 |
|---|---|---|---|
| アタッカー (DPS) | 武器 (剣) | グローブ | 攻撃力＋クリティカルがダメージに直結。チェストプレートは後回し（戦闘への寄与が低いため） |
| タンク | チェストプレート | ブーツ | HP/DEFで前線を維持。**タンクの武器にストーンを消費してはいけない** |
| アタッカー順 (アニー/ピエロ) | 剣 → グローブ → ブーツ → 防具 | | DPSアタッカー向けのコミュニティ推奨順 |

> [!WARNING] タンク武器の罠（見せかけの戦力）
> タンクの剣をギアストーンで精錬すると、プロフィール上の戦力値は上がりますが、**実際の戦闘ではほぼ無意味**です。タンクは生存してダメージを肩代わりすることで勝利に貢献するのであり、通常攻撃で戦うわけではありません。貴重なギアストーンをタンクの武器に浪費せず、アタッカーの剣とグローブに直接投入してください！同様に、アタッカーのチェストプレートに過剰投資するのも避けましょう。わずかな防御力上昇では、脆いアタッカーを守ることはできません。

## 精錬工房：レベル25がスイートスポット {#smelters}

5つの精錬工房は、ギアストーンの受動的な収入源です。

- 各工房は**レベル23〜25**まで上げるべきです。レベル25がスイートスポットであり、それ以上はコストが急激に跳ね上がる一方で、得られる恩恵は頭打ちになります。
- 工房5つをレベル25にすると、**約265ストーン/時間 ≈ 6,000/日 ≈ 44,000/週**の受動収入となります。
- これに秘密工作（URミッション達成で週約33,000）、KvK報酬（約14,000）、ウィークリーショップ購入（10,000×2）、同盟決闘のフェーズ報酬（約33,000）を合わせると、無課金プレイヤーの計算では**週あたり約131,000ギアストーン**となり、週に1回レベル40のブレイクポイントを突破できる計算になります。

## 装備市場のメカニズム：製作、融合、焼入れ鋼 {#crafting-math}

- 青以外の装備はすべて分解し、その結果得られる素材を**4 → 1**の比率で融合させ、**焼入れ鋼（焼入れ鋼）**にします。これはUR武器、UR防具、およびレベル40以降のすべてのアップグレードに必要な素材です。
- UR装備の製作には、**500,000ハーブ**と、工房レベルが低い場合で**約1日5時間**を要します（工房レベルが高いほど短縮されます）。
- **SSRグローブ**は、ワールドボスや魔王戦で必要とされる場合にのみ製作してください（PvEにおいて、モンスターへのダメージ+6%は代えがたい効果です。終了後はURグローブに戻しましょう）。

## レベル40スタッキングのコツ {#level-40-jump}

装備のステータスはレベル40までは線形に上昇しますが、それ以降は**不釣り合いに跳ね上がります**。レベル40以上の剣は、レベル36〜39の時よりもストーンあたりの攻撃力/クリティカル上昇率がはるかに高くなります。実用的なルールとして、**一気にレベル38から42以上に引き上げられるまで**ストーンとハーブを貯め込みましょう。成長曲線が最も緩やかな段階で少しずつ消費してはいけません。

## 装備昇格と専用武器精錬 {#promotion}

2026年5月のアップデート以降、装備はレベル**10、20、30、40**で設計図を使用して**昇格**させることができ、レベル40を超えて最大**60**まで強化可能です。素材の総コストは旧システムと変わりません。昇格により追加のボーナスステータスが解放されます。高ランクの昇格こそが、長期的な装備強化の主な目標です。

### 専用武器精錬（10星精錬） {#exclusive-smelt}
専用武器が**10星**に達すると、**精錬（Smelt）**機能が解放されます（2026年8月20日アップデート）。これにより、二次戦闘属性（クリティカルダメージ、防御貫通、ライフスティール）をさらに強化できます。

## ボス戦用装備（魔王） {#boss-gear}

反撃してこないボスに対しては、通常のルールが逆転します。

- **武器：最高レベルのURの剣** — 「+0のURの剣は、+30のSSRの剣よりもダメージが出る」（攻撃力とクリティカル率がスキルの基礎ダメージに影響するため）
- **グローブ：URではなくSSR！** レベル30のSSRグローブは**対モンスターダメージ+12.25%**を付与し、SSRグローブの補正は最終ダメージに適用されます。一方、URグローブは（効果の低い）攻撃力を上昇させ、役に立たないダメージ耐性を追加するだけです。
- **ブーツとチェスト：ボス戦では無関係** — どのレベルでも問題ありません。

## Raven装備 {#raven-gear}

Ravenには専用の装備セットがあります（左側：HP/クリティカルダメージ軽減、右側：攻撃力/クリティカルダメージ）。パーセンテージバフが発動する**レベル8**を目指して強化しましょう（レベル8以上の装備については研究進捗が表示されるようになっています）。**Raven装備の宝箱は同盟決闘の日まで温存**しておきましょう。開封することでイベントポイントを獲得できます。

特殊効果セット（Night Raven Mask、Raven Feather Cloakなど）は、各パーツが指定レベルに達すると発動します（2026年3月アップデートで追加）。

## 素材の入手方法 {#materials}

- **精錬工房 → レベル25：** 聖域で可能になり次第、精錬工房をレベル25まで上げましょう。装備レベルアップに必要なギアストーンを精錬・生産します。この建物の強化が遅れると、アタッカーの武器強化において乗り越えられないボトルネックとなります。
- **装備工房** — 製作と分解。**織物工房**は融合や製作に必要な布を生産します。
- **ギアストーンの無課金ファーム：** コミュニティにおける最大のボトルネックはギアストーンです。聖域ショップと遠征ショップで欠かさず購入しましょう。
- **名誉ショップの装備設計図（UR）：** 名誉コインは**装備設計図（UR）にのみ**費やしてください。キュリオ宝箱や万能欠片はスキップしましょう。設計図こそが、オレンジ装備をレベル10、20、30、40へ昇格させるための唯一の関門です。

## コミュニティクラフト順序 (DTFプラクティス) {#dtf-craft-order}

この実践ガイドでは、ポートレート（外見）ではなく役割ごとに装備を作成します：メインDPS、セカンドDPS、メインタンク、セカンドタンク、そしてサポートです。各役割を実際に誰が担当するかはアカウントによって異なります（Marlena、Red Lady、またはその他のキャリー；Arthur、Daskal、Louis、またはその他のフロント）— 機能を基準にアイテムを決定します。

![装備ガイド：誰に何を最初に持たせるか](/img/dtf/gear/01.jpg)

### 紫装備はゴミではありません {#dtf-purple-base}

ゴールドの代替品が存在するまで、紫装備を不要なものとして扱わないでください。ルールは単純です：**メインの5人は常に装備を着ていること** — 完璧である必要も、すぐにゴールドになる必要もありませんが、空きスロットを作らないようにしてください。空きスロットはステータスの損失であり、「なぜまた負けたのか」という状況をすぐに引き起こします。2軍や3軍には紫を維持させ、メインチームが安定するまでゴールドの資源はメインチームに温存します。

![紫とゴールドのヒーロー装備](/img/dtf/gear/02.jpg)

### このチャプターにおけるスクワッドの役割 {#dtf-squad-roles}

1. メインDPS — ダメージの大部分を担う。2. セカンドDPS — トドメを刺し、バックラインにプレッシャーをかける。3. メインタンク — 攻撃を受け止める。4. セカンドタンク — 前衛の崩壊を防ぐ。5. サポート — 回復、バフ、救助。

![役割を持ったメインスクワッド](/img/dtf/gear/03.jpg)

### 最初のゴールド：メインキャリーの剣 {#dtf-swords-first}

よくある最初の間違いは、タンクから始めることです。ダメージがなければ、タンクはただ負け試合を長引かせるだけになります。したがって、1つ目のアイテムは**メインアタッカー用のゴールドの剣**です：キャリーの基礎ステータスとクリティカルを全体的にスケールアップさせます。戦闘はしばしば、最も巨大なシールドを持つ側ではなく、敵のバックラインを最初に突破した側によって決まります。

![最初のクラフトとしてのメインキャリー用ゴールドの剣](/img/dtf/gear/04.jpg)

2つ目のアイテムもダメージ用です：**セカンドアタッカー用の剣**。1人のキャリーは対策される可能性がありますが、2人いれば安定性、フィニッシュ能力、そしてスキルの価値が高まります。

### 次：両方のアタッカー用グローブ {#dtf-gloves-next}

3つ目と4つ目のアイテムは**グローブ（最初にメイン、次にセカンド）**です — 攻撃力の上昇に加え、すでに剣が与えている効果と重複する有用なステージボーナスが得られます。2本の剣と2つのグローブが、最初の本格的な攻撃の枠組みを形成します。

![アタッカー用の剣をLv20、グローブをLv10に](/img/dtf/gear/05.jpg)

### なぜタンクより先アタッカーに防具を回すのか {#dtf-armor-dd-first}

タンクは基礎HPと防御力が高く、紙装甲のアタッカーは主要スキルを使う前に倒されてしまいます。そのため、5つ目と6つ目のアイテムは**メインおよびセカンドDPS用の防具**です（生存してスキルを放ち、クリティカルを出してターゲットを引き裂くため）。その後にようやく2人のタンク用防具（7つ目、8つ目）となります。前衛も重要ですが、まずはダメージを与える機会を確保しなければなりません。

### ブーツ：コア4人のためのエネルギー耐性 {#dtf-boots-energy}

主要レベルのブーツは**エネルギーダメージ耐性**を付与します。戦闘レポートによると、これは敵キャリーのスキルからバックラインとフロントラインの両方が受けるダメージです。クラフトの順番：メインDPS、セカンドDPS、メインタンク、セカンドタンクの順にブーツ（9〜12番目）。

![保護のためのSSR防具とブーツ](/img/dtf/gear/06.jpg)

### 次にタンクのグローブとタンクの剣 {#dtf-tank-gloves-swords}

コア4人がブーツを装備した後：両タンクのグローブ（13、14番目）、次に両タンクの剣（15、16番目）。タンクの剣は最初ではありませんが、終盤で役に立たないわけではありません。エンドゲームではステータスが重要であり、一部のタンクのスキルはダメージや回復と連動しています。

### サポートは最後 — だが劣っているわけではない {#dtf-support-last}

サポートの役割は生存し、スキルを放ち、バフをかけることであるため、最初の剣を争う必要はありません。順番：**防具 → ブーツ → グローブ → 剣**（17〜20番目）。防具とブーツで生存力を確保し、グローブでパラメータを上げ、コア4人が装備を調えた後の最後の仕上げとして剣を持たせます。

![役割に基づいた装備クラフトの順序](/img/dtf/gear/07.jpg)

### レベルの閾値：最初に20、次に40 {#dtf-level-thresholds}

クラフトはまだ始まりに過ぎません。最初の本当の壁：**メインキャリーの剣をLv20にする**（剣のプロジェクト全体が存在する理由であるクリティカルボーナス）、次にメインのグローブをLv10に；セカンドキャリーでも同様に繰り返します（剣Lv20、グローブLv10） — これが最初の攻撃の最低ラインです。その合間にタンクの防具、サポートのブーツ、セカンドタンクの剣に浮気してはいけません。そうしないと何も尖った性能になりません。

次の生存力は**ブーツをLv20にする**（エネルギー耐性）ことで得られます。順番は メインDPS → セカンドDPS → メインタンク → セカンドタンク → サポート です。次に**防具をLv20にする**（メインタンク、セカンドタンク、メインDPS、セカンドDPS、サポート — レポートに応じて調整：バックラインが急速に倒れるならDPS防具を早めに；前衛が溶けるならタンクを優先）。

そして本格的な育成フェーズへ：キャリーの剣を現在のスター上限に向かって強化（最初にメイン、次にセカンド）、次にDPSのグローブ、そして防御力。**コア4人のブーツをLv40にする**のは、エネルギーメタに対する最高の防御策の1つです — ヒーローが生き延びてもう1つスキルを発動できるようになり、それが勝敗を分けることがあります。次に**タンクの防具をLv40にする**（前衛の物理ボーナス）、DPSの防具（道中の基本ステータスとHPのためにLv30、将来的にはLv40）。サポート：ブーツをLv20/40、防具をLv20/40、グローブ、そして最後に剣。

### スター（星章）：本当の苦難が始まる場所 {#dtf-star-order}

スターは装備工房（Gear Workshop）がレベル20に達するとアンロックされ、設計図を使用して強化します：1つ星 = 5個、2つ星 = +10個、3つ星 = +15個、4つ星 = +20個（**1アイテムあたり50個の青い設計図で4つ星へ**）；5つ目の星には赤い設計図が必要です — メインヒーローに長く使い続けるアイテムのための贅沢なプロジェクト（最初にメインDPS、次にセカンドDPS、そしてチームの防御）。

![工房と名誉ショップの設計図](/img/dtf/gear/08.jpg)

スターの順序：**メインキャリーの剣に2つ星**（ステータス上昇と上限解放） → メイングローブに1つ星 → セカンドキャリーの剣に2つ星 → セカンドグローブに1つ星 → メインの剣を4つ星へ → コア4人のブーツに2つ星 → DPSのグローブ、防具、タンク、そして5つ星の鍵。剣の効果は戦闘ダメージをスケールさせます；防具はクリティカル対策になり；ブーツはクリティカルダメージを軽減し；グローブはダメージと耐性を追加します — しかし、赤い設計図はパーティーの配り物ではありません。

### 設計図の入手場所 {#dtf-blueprint-sources}

設計図は名誉ショップやメダルイベント（アリーナ、エリクサー、キングダムウォー、キャニオン、クリスタルバレー）に紐づいています。設計図が不要に感じられるときでも、名誉通貨のイベントを絶対に見逃さないでください — 後々、最も厳しいボトルネックになります。まずアイテムを決め、それからそれに合わせて集めてください。

### 1つの強力なスクワッドは、中途半端な2つに勝る {#dtf-one-squad}

玉座、塔、城、アリーナ、エリクサー、キャニオン、クリスタルバレー：メインスクワッドは相手を圧倒できなければならず、中途半端な2つ目のスクワッドではそれを救えません。まずメインスクワッドを最大化し、次にセカンド、そしてサードへと進めます。クラフト、レベル、スターの早見表：

クラフト：剣 メインDPS → 剣 セカンドDPS → グローブ メイン → グローブ セカンド → 防具 メインDPS → 防具 セカンドDPS → 防具 メインタンク → 防具 セカンドタンク → ブーツ ×4 → タンクグローブ ×2 → タンクの剣 ×2 → サポート 防具/ブーツ/グローブ/剣。

![5人のヒーローのためのゴールド装備クラフトスキーム](/img/dtf/gear/09.jpg)

レベル：剣 メインをLv20 → グローブ メインをLv10 → 剣 セカンドをLv20 → グローブ セカンドをLv10 → コア4人のブーツをLv20 → タンクおよびDPSの防具をLv20 → DPSの剣を上限まで → コア4人のブーツをLv40 → タンクの防具をLv40 → DPSのグローブ/防具を進める → サポートは最後。

![レベル早見表](/img/dtf/gear/10.jpg)

スター：2★ 剣 メイン → 1★ グローブ メイン → 2★ 剣 セカンド → 1★ グローブ セカンド → 剣 メインを4★へ → コア4人のブーツを2★ → DPSのグローブ、防具、タンク、5★の鍵。

迷ったときは：これは私のメインダメージを上げるか、メインスクワッドがスキルを発動するまで生き残る助けになるか？ 光る赤いドットはあなたの上司ではありません。
