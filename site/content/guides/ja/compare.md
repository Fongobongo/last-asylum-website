## マーレナ vs ゾーヤ — どちらのURキャリー？ {#marlena-vs-zoya}

**✓ まずマーレナ、次にゾーヤ**

| | | |
|---|---|---|
| **入手方法** | $1チャージで初日から、酒場で66日目に無料 | 有料のみ（断片10個で開始） |
| **ダメージシェア** | 編隊ダメージの約85%を単独で | 最大化されたマーレナと約50/50で分け合う |
| **ダメージタイプ** | ビルドにより物理/エネルギー混合 | エネルギー旋風 — エネルギーサポートが必要 |
| **シナジー** | 標準編成（ハーパーULT + ベル + クレアパッシブ）で4倍バフ | 物理ジョーカーとはスタックしない |
| **F2P評価** | F2Pパス全体のメインキャリー | ゾーヤの星が高い場合のみクレアを交代 |

## シンシア vs マーレナ (F2P向け) {#cynthia-vs-marlena-f2p}

**✓ $1を払う — しかし、どうしても無理ならシンシアでも可**

| | | |
|---|---|---|
| **コスト** | 約1,500ダイヤ（無料ガチャ7回 + 報酬の断片10個でフルコピー） | $1チャージ（初日、または酒場で66日目に無料） |
| **序盤の強さ** | 序盤の強力なキャリー（レンジャーUR） | 後半型 — 高星になるまで弱い |
| **終盤** | 勢力ボーナス5% + ハーパー/エピグラフのシナジーを失う | ウォーリアー単一編成の核 |
| **ホイールのタイミング** | 1〜8日目のダイヤを温存する必要がある | ダイヤコストなし |
| **評価** | 序盤は viable、後半は失速 | シンシアより常に推奨される |
