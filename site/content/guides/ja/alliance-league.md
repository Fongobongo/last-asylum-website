## 📚 リファレンス：アライアンスリーグ：エリート、エピック、ミシック {#wiki-alliance-league}

出典: [wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/alliance-league)、クライアント v1.0.87。

アライアンスリーグは、ディビジョン昇格を目指すアライアンス間のシーズン制対抗戦です。報酬は「アライアンスの最終順位」と「アライアンス内でのプレイヤーの順位」という2つのランクによって決まります。強力なアライアンスに所属しているだけでは不十分であり、個人の順位によって報酬テーブルのどの行が適用されるかが決定されます。報酬の大部分は「学習の巻物（Study Scrolls）」で支払われます。

各リーグには独自の報酬テーブルがあり、アライアンス順位とアライアンス内順位を組み合わせて報酬が決定されます。

## エリートリーグ

報酬はアライアンス順位とアライアンス内順位の両方に依存します。

| アライアンス順位 | アライアンス内順位 | 学習の巻物 |
|---|---|---|
| 1-1 | 1-10 | 1,100 |
| 1-1 | 11-30 | 1,050 |
| 1-1 | 31-100 | 1,000 |
| 2-3 | 1-10 | 1,000 |
| 2-3 | 11-30 | 950 |
| 2-3 | 31-100 | 900 |
| 4-16 | 1-10 | 900 |
| 4-16 | 11-30 | 800 |
| 4-16 | 31-100 | 750 |

## エピックリーグ

報酬はアライアンス順位とアライアンス内順位の両方に依存します。

| アライアンス順位 | アライアンス内順位 | 学習の巻物 |
|---|---|---|
| 1-1 | 1-10 | 2,100 |
| 1-1 | 11-30 | 1,950 |
| 1-1 | 31-100 | 1,650 |
| 2-3 | 1-10 | 1,650 |
| 2-3 | 11-30 | 1,500 |
| 2-3 | 31-100 | 1,400 |
| 4-16 | 1-10 | 1,400 |
| 4-16 | 11-30 | 1,250 |
| 4-16 | 31-100 | 1,100 |

## ミシックリーグ

報酬はアライアンス順位とアライアンス内順位の両方に依存します。

| アライアンス順位 | アライアンス内順位 | 学習の巻物 |
|---|---|---|
| 1-1 | 1-10 | 3,120 |
| 1-1 | 11-30 | 2,980 |
| 1-1 | 31-100 | 2,760 |
| 2-3 | 1-10 | 2,760 |
| 2-3 | 11-30 | 2,550 |
| 2-3 | 31-100 | 2,380 |
| 4-16 | 1-10 | 2,380 |
| 4-16 | 11-30 | 2,250 |
| 4-16 | 31-100 | 2,100 |

報酬の幅は、最低リーグの下位で750巻物、最高リーグの1位で3,120巻物となっています。比較として、アライアンスデュエル（Alliance Duel）の週報酬は勝利で840巻物、敗北で420巻物です。デュエルの研究ツリー全体には54,110巻物が必要となるため、1つのリーグシーズンはデュエルの1週間分よりも大きな価値があります。

ディビジョンを昇格すると報酬はほぼ倍増しますが、同じアライアンス内で100位から10位に順位を上げることで得られる増加分はそれよりも小さいため、昇格を目指すことの方がより価値のある目標となります。
