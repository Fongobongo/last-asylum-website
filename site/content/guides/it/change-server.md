Cambiare server in Last Asylum: Plague significa creare un nuovo personaggio da zero: il gioco non ha alcun meccanismo per spostare una città tra server, e gli eroi e le skin acquistate non si trasferiscono su uno nuovo. Tutto ciò che i giocatori cercano sotto la voce "cambio di server" si riduce a quattro questioni: come avviare un personaggio su un altro server, perché alcuni server rifiutano i nuovi arrivati, su quale orologio gira il server e se è imminente una migrazione. I fatti sono stati verificati il 9 settembre 2026 rispetto al gioco e alle segnalazioni dei giocatori.

## Non è possibile spostare una città

Il server assegnato dal gioco a un personaggio rimane lo stesso per sempre. I progressi, le risorse, gli eroi e ogni singolo acquisto sono legati a quel personaggio e non possono essere portati altrove. L'unico modo per accedere a un altro server è creare un nuovo personaggio: la schermata di accesso offre un elenco di server e una città lì ricomincia dal livello uno. Il vecchio personaggio rimane dove si trovava, un account può contenere più personaggi su server diversi e il passaggio tra di essi avviene tramite lo stesso elenco di server. Il funzionamento dell'account e del suo collegamento è descritto nella pagina Account.

Gli eroi acquistati sono assenti sul nuovo server: un pass eroe si applica solo al personaggio per cui è stato comprato. I giocatori che hanno provato a trasferirsi per raggiungere gli amici mettono in guardia su questo aspetto separatamente, poiché l'errore costa denaro.

## Server che rifiutano i nuovi arrivati

L'elenco dei server nella schermata di accesso non mostra tutti i server esistenti. I server che sono entrati nell'Era della Rinascita sono chiusi ai nuovi personaggi, quindi non è più possibile unirsi a un amico lì dentro. I giocatori interpretano questo come una protezione per i nuovi arrivati: un personaggio appena creato su un server più vecchio di centotrenta giorni non avrebbe alcuna possibilità. I cambiamenti introdotti dall'Era sono trattati nella pagina Stagioni ed Era.

Il numero del server è visibile nel profilo: l'icona del profilo nell'angolo in alto a sinistra, con un numero come #218 accanto al nome. I nuovi server aprono più volte alla settimana; alla fine di agosto 2026 i numeri avevano superato quota trecentotrenta.

## Quando ha aperto un server

L'età del server determina quali eventi sono già attivi e a che punto è l'Era della Rinascita, mentre i numeri dei server vengono assegnati in ordine di apertura. ## Ora del server

Ogni evento, ripristino e coda dei titoli si basa sull'ora del server anziché sull'orologio del telefono. In base all'osservazione dei giocatori, l'orologio del server è indietro di due ore rispetto al Tempo Coordinato Universale (UTC-2), e la maggior parte degli eventi include un'opzione per mostrare la stessa programmazione nell'ora locale. Il programma degli eventi per giorno del server è raccolto nella pagina Eventi.

## Visitare un altro server

È possibile osservare un altro server dalla schermata della carovana: invece di attaccare una carovana, si scorre la mappa per ispezionare territori stranieri e si cerca un server tramite il suo numero. Il secondo percorso passa attraverso la Guerra tra Regni: la scheda delle informazioni sull'abbinamento elenca il gruppo di server e il suo pulsante Visualizza sposta la telecamera in un regno straniero. Le coordinate di una città straniera vengono salvate contrassegnandole con una stella, etichettata come amica o nemica.

Il teletrasporto con le truppe su un altro server funziona solo contro l'avversario del Duello tra Alleanze nel giorno dei raid e contro gli avversari della Guerra tra Regni, e tale spostamento dura un giorno. Il saccheggio delle carovane e le operazioni coperte sono consentiti solo sui server dello stesso gruppo, e la casella di controllo "escludi il proprio server" nella schermata della carovana rimuove dall'elenco i vicini che la maggior parte dei server vieta di attaccare secondo le proprie regole.

## Se la migrazione arriverà

La risposta ufficiale degli sviluppatori nella community è la stessa dalla primavera del 2026: i trasferimenti tra server sono previsti, ma senza una data di scadenza. Voci su un biglietto d'oro, fusioni di server e uno spostamento "con tutti i progressi" provengono dai giocatori, non dall'editore. Separatamente, un'offerta in messaggi privati o su Discord per "spostarsi su un altro server perché questo sta chiudendo" è un trucco da reclutatore per un altro gioco, trattato nella pagina delle FAQ.
