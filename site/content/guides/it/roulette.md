La Ruota dei Desideri gira tramite monete: un singolo giro costa 1 Moneta del Desiderio e dieci giri consecutivi costano 10. Ogni giorno viene regalata una moneta, quindi vale la pena sfruttare il giro gratuito. Ci sono due ruote: la prima offre frammenti di un eroe specifico e la seconda risorse per il corvo.

## Ruota dell'eroe

La prima tabella elenca ogni elemento presente sulla ruota dell'eroe insieme alla sua probabilità.

| Probabilità | Premio |
|---|---|
| 21.50% | Pietra per equipaggiamento x120 |
| 20.80% | Fornitura di antitossina di livello (SR) x11 |
| 13.10% | Distintivo abilità x110 |
| 11.40% | Pietra per equipaggiamento x180 |
| 9.97% | Frammento di Cynthia x1 |
| 9.97% | Frammento di Cynthia x1 |
| 9.96% | Frammento di Cynthia x1 |
| 1.00% | Frammento di Cynthia x5 |
| 1.00% | Frammento di Cynthia x2 |
| 1.00% | Frammento di Cynthia x2 |
| 0.20% | Spada UR x1 |
| 0.10% | Frammento di Cynthia x100 |

I frammenti compaiono in circa un terzo dei giri, ma quasi sempre uno alla volta, mentre le vincite più consistenti rimangono rare.

## Ruota del corvo

La seconda tabella è strutturata allo stesso modo e copre la ruota del corvo.

| Probabilità | Premio |
|---|---|
| 25.90% | Essenza di corvo x2 |
| 22.00% | Frutti di corvo da 1K x6 |
| 20.90% | Bauli equipaggiamento corvo Liv. 2 x1 |
| 20.20% | Frutti di corvo da 1K x6 |
| 5.90% | Frutti di corvo da 10K x2 |
| 2.00% | Essenza di corvo x10 |
| 1.50% | Bauli equipaggiamento corvo Liv. 4 x1 |
| 1.00% | Essenza di corvo x4 |
| 0.30% | Essenza di corvo x100 |
| 0.10% | Frammento universale eroe UR x100 |
| 0.10% | Bauli di scelta equipaggiamento corvo Liv. 5 x1 |
| 0.10% | Bauli equipaggiamento corvo Liv. 5 x1 |

Quella ruota non assegna quasi nessun frammento di eroe e ripaga invece con frutti ed essenza di corvo, che rappresentano la voce di spesa più pesante nello sviluppo del corvo.
