Dilek Çarkları jetonlarla döner: tek bir çevirme 1 Dilek Jetonuna mal olur ve art arda on çevirme 10 jetona mal olur. Her gün bir jeton ücretsiz gelir, bu nedenle ücretsiz çevirmeyi yapmaya değer. Biri belirli bir kahramanın parçaları, diğeri ise kuzgun kaynakları için olmak üzere iki çark bulunmaktadır.

## Kahraman Çarkı

İlk tablo, kahraman çarkındaki her bir girdiyi ve çıkma olasılığını listeler.

| Olasılık | Ödül |
|---|---|
| %21,50 | Dişli Taşı (Gearstone) x120 |
| %20,80 | Antitoksin Seviye İkmali (SR) x11 |
| %13,10 | Yetenek Rozeti (Skill Badge) x110 |
| %11,40 | Dişli Taşı (Gearstone) x180 |
| %9,97 | Cynthia Parçası x1 |
| %9,97 | Cynthia Parçası x1 |
| %9,96 | Cynthia Parçası x1 |
| %1,00 | Cynthia Parçası x5 |
| %1,00 | Cynthia Parçası x2 |
| %1,00 | Cynthia Parçası x2 |
| %0,20 | UR Kılıç x1 |
| %0,10 | Cynthia Parçası x100 |

Parçalar çevirmelerin yaklaşık üçte birinde çıkar, ancak neredeyse her zaman teker teker gelir ve daha büyük ödüller nadir kalır.

## Kuzgun Çarkı

İkinci tablo da aynı şekilde oluşturulmuştur ve kuzgun çarkını kapsar.

| Olasılık | Ödül |
|---|---|
| %25,90 | Kuzgun Özü (Raven Essence) x2 |
| %22,00 | 1K Kuzgun Meyvesi x6 |
| %20,90 | 2. Seviye Kuzgun Ekipman Sandığı x1 |
| %20,20 | 1K Kuzgun Meyvesi x6 |
| %5,90 | 10K Kuzgun Meyvesi x2 |
| %2,00 | Kuzgun Özü (Raven Essence) x10 |
| %1,50 | 4. Seviye Kuzgun Ekipman Sandığı x1 |
| %1,00 | Kuzgun Özü (Raven Essence) x4 |
| %0,30 | Kuzgun Özü (Raven Essence) x100 |
| %0,10 | UR Kahraman Ortak Parçası x100 |
| %0,10 | 5. Seviye Kuzgun Ekipman Seçim Sandığı x1 |
| %0,10 | 5. Seviye Kuzgun Ekipman Sandığı x1 |

Bu çark neredeyse hiç kahraman parçası vermez ve bunun yerine kuzgun gelişimi için en büyük harcama kalemi olan kuzgun meyvesi ve özü öder.
