> Dane zweryfikowane z klientem gry (wersja 1.0.87, źródło: [wiki-last-asylum.com](https://wiki-last-asylum.com/en/wiki/roulette)).

Koła Życzeń kręcą się za monety: pojedyncze zakręcenie kosztuje 1 Monetę Życzeń, a dziesięć zakręceń z rzędu kosztuje 10. Każdego dnia otrzymujesz jedną darmową monetę, więc warto wykonać darmowe zakręcenie. Dostępne są dwa koła: pierwsze dotyczy odłamków konkretnego bohatera, a drugie zasobów kruka.

## Koło bohatera

Pierwsza tabela zawiera wszystkie pozycje na kole bohatera wraz z ich szansą na trafienie.

| Szansa | Nagroda |
|---|---|
| 21.50% | Kamień zębaty (Gearstone) x120 |
| 20.80% | Zaopatrzenie w antytoksyny poziomu (SR) x11 |
| 13.10% | Odznaka umiejętności (Skill Badge) x110 |
| 11.40% | Kamień zębaty (Gearstone) x180 |
| 9.97% | Odłamek Cynthii x1 |
| 9.97% | Odłamek Cynthii x1 |
| 9.96% | Odłamek Cynthii x1 |
| 1.00% | Odłamek Cynthii x5 |
| 1.00% | Odłamek Cynthii x2 |
| 1.00% | Odłamek Cynthii x2 |
| 0.20% | Miecz UR x1 |
| 0.10% | Odłamek Cynthii x100 |

Odłamki pojawiają się w około jednej trzeciej losowań, ale prawie zawsze pojedynczo, natomiast większe wygrane pozostają rzadkością.
