## 말레나 vs 조야 — 어떤 UR 캐리를 선택할까? {#marlena-vs-zoya}

**✓ Marlena를 먼저, Zoya는 나중에**

| | | |
|---|---|---|
| **획득 방법** | 1일 차 1달러 충전, 66일 차 선술집(선술집) 무료 획득 | 유료 전용 (시작 시 조각 10개 필요) |
| **데미지 비중** | 스쿼드 데미지의 약 85%를 단독으로 담당 | 육성이 완료된 Marlena와 약 50/50으로 분담 |
| **데미지 유형** | 빌드에 따라 물리/에너지 혼합 | 에너지 회오리 — 에너지 서포터 필요 |
| **시너지** | 표준 조합에서 4배 버프 (하퍼 궁극기 + 벨 + 클레아 패시브) | 물리 Joker와 중첩되지 않음 |
| **무과금(F2P) 판정** | 무과금 경로 전체의 핵심 메인 캐리 | Zoya가 고성급일 때만 Claire를 교체 |
